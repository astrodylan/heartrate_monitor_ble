# Manual for the Client and Server 

Welcome and thanks for using my system. In this manual, I will guide you throught the system; both the client and the server side. 


## Components
### Software
When you download a version form the **[Releases](../../releases)**, please make sure you download the correct version for your operating system. When selecting your version, it downloads the excecutable version of the client. 

For the server side, you need to download the server/server.py code. This is for now running python so make sure this is available on your server.

### Hardware
For the hardware are many option. Almost all devices that broadcast the heartrate unencripted. For the complete list see [Device List](../DEVICELIST.md) for the latest expected and validated devices.
